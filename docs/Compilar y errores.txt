A. Identificar y eliminar código inalcanzable
    Habilita advertencias del compilador
    Ajusta tu línea de compilación para que te avise de código inalcanzable y dead code. Por ejemplo con g++:

g++ -Wall -Wextra -Wunreachable-code *.cpp -std=c++17

Esto marca bloques tras un return, exit() o break que nunca se ejecutan.

Revisa cada advertencia
    Ve al archivo y línea que señala el compilador.
    Confirma si realmente ese fragmento ya no sirve (por ejemplo, un if (false) o código después de un return).

Elimina o comenta
    Borra las líneas o bloques muertos.
    Si no estás 100 % seguro, coméntalas primero (// …) y vuelve a compilar; si nada falla, puedes borrarlas definitivamente.

Chequea funciones/variables no usadas
    Busca en todo el proyecto llamadas a cada función y referencias a cada variable global o estática.
    Si ninguna la usa, retírala del header y de la implementación.

Prueba funcional
    Vuelve a compilar sin advertencias.
    Ejecuta una partida rápida para confirmar que no has eliminado nada esencial.
