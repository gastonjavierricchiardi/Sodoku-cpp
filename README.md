# Sodoku C++ (Sudoku)

Implementación de Sudoku en C++ con modo de juego y utilidades internas.

## Estructura
- `src/` código fuente
- `include/` headers
- `scripts/` scripts de build
- `docs/` documentación del proyecto

## Compilar (Linux)
Ver `scripts/build_linux.sh`.

## Compilar (Windows)
Ver `scripts/build_windows.sh`.

## Estado
Proyecto en evolución. PRs y sugerencias son bienvenidas.
